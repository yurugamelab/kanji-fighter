# 漢字ファイター

好きな漢字を1文字えらぶと、それを武器にしたキャラが勝手に殴り合うバカ格闘ゲーム（オートバトル）。スマホ縦向き向けに作っていて、PCでも遊べる。

## 遊び方
`index.html` をブラウザで開くだけ（インストール不要）。

1. 武器にする漢字を1文字入力する（攻撃力・速さ・リーチ・効果が表示される）
2. 「この字で戦う」を押すと、CPUが選んだ漢字と自動で戦う（1回戦・60秒）

3. 結果画面のカード画像を保存して、Xでシェアできる

- **勝ち抜き**：入力画面で「1回勝負／勝ち抜き」を切り替える。負けるまで連戦し、毎試合HP満タンで戦う（前の試合のダメージは持ち越さない）。相手は1人ごとに画数が増える（1人目は2〜7画、11人目で20画超え、15人目あたりから30画超えの巨大な字）。5人目・10人目・15人目…はボスで、特別な字が出る。勝つほど相手は打たれ強くなる。10連勝できる確率がだいたい5%になるように合わせてある（数字は `game.js` の `SURV`。16字で1人目〜10人目を各20試合ずつ自動対戦させて、勝率の掛け算で約4.6%）。10連勝ごとに道場が夕暮れ→夜→赤い月に変わる。結果画面で連勝数に応じた称号がもらえる（0〜2連勝 見習い → 3〜5 一人前 → 6〜8 プロの漢字ファイター → 9 伝説の漢字ファイター → 10〜 漢字ファイターの神）。最高記録は端末に保存。
- **漢字図鑑**：タイトル・入力画面・結果画面から開く。特別な100字の発見状況、未発見の字のヒント、見つけた字の効果・初めて使った日・その字での勝ち数が見られる。
  - 特別な字で**勝つと**図鑑に登録される（負けたり引き分けたりした字は登録されない）。登録されると、字が図鑑のマスへ飛んでいって埋まる演出が出る（発見数のバーが伸び、あと何字か・次に探す字のヒントも出る）。
  - 神・龘の封印が解けたときは特別な演出：暗転して後光が差し、字が天から降りてきて白く光り、金色のマスにはまる。X で自慢できるボタンが出る（演出は `game.js` の `DexReveal`）。
- **ふたりで対戦**：タイトルの「ふたりで対戦」から。1Pが字を選ぶ →「2Pに渡してね」画面 → 2Pが字を選ぶ → 対戦（お互いの字はVSで初めて見える）。

- **必殺技**：緑のバーがHP、その下の黄色いバーが必殺ゲージ。必殺ゲージは**殴られた分だけ溜まる**ので、劣勢な側の逆転の一手になる（1試合に1回くらい）。
  - 満タンになっても、すぐには撃たずに相手の隙（状態異常で動けない・攻撃を空振りした）を狙う。隙を突けば必ず当たる。
  - 待ちきれずに撃つ（1.5秒以上待ったとき、HPが少なくて焦ったとき）と、相手に「読まれて」ガードされたり（ダメージ4分の1・効果なし）、近づく技なら「見切られて」避けられたりする。
  - 撃つと画面が止まってカットイン → 力をためる → スローで技が出る。特別な字は字ごとに技名と演出がある（炎「紅蓮獄炎」、氷「絶対零度」など。技名は漢字だけ・6文字まで）。演出は49種類（母「千本葱舞」はネギが降り注いで最後に特大のネギ、筋「筋肉感謝祭」はダンベルの雨と巨大バーベル、鮨「無限寿司地獄」は寿司の雨のあと相手を巨大な握り寿司にする、税「増税地獄」は請求書の雪崩と巨大な「増税」の判子、罰「天罰覿面」は空が割れて雷、悪「極悪非道」は暗転と高笑いのあと背後から一撃、魂「魂魄解放」は人魂の渦、乙「定時退勤」は17時のチャイムで何度も駆け抜ける、鎌「死神大鎌」は死神の大鎌（HP3割以下なら刈り取りで2倍）、霊「百鬼夜行」はお化けの行列、蹴「必殺蹴球」は足もとの字を蹴り上げ、落ちてきたところをボレーで燃えるシュート（キャラが本当に脚を振る）、岩「巨岩崩落」はたくさんの岩が落ちてきて最後に大きい岩、砂「無限蟻地獄」は相手の足元がすり鉢状にくぼんで砂に沈んでいく、花「百花繚乱」は地面から花が次々に咲き広がり最後に巨大な花が開く、愛「重愛圧殺」は巨大なハートが落ちてきて押しつぶす、神「神罰執行」は天が開いて光の柱が降り注ぎ、最後に金色の巨大な『神』が降臨する、卍「卍字大旋風」はたくさんの卍が飛んでいって次々に当たる、鎖「獄鎖縛陣」は鎖でぐるぐる巻きにして締め付ける、盾は巨大な盾で体当たり、鐘は巨大な鐘をかぶせる、牛は字の群れが駆け抜ける、金は札束で何度もはたく、運は大吉のおみくじが大量に飛んでくる、など）。ふつうの字は、字が巨大化して3回振り回す「巨大○旋風」。
- **コンボ**：武器で当てたとき、ときどき次の技につながる（2連・3連コンボ）。1試合に2連が2回くらい、3連はたまに。
- **テンポ**：1試合はだいたい20〜45秒。ダメージ全体の倍率は `game.js` の `DMG`、AIの反応の遅れは `Ai.think` の最後で変えられる。
- **音楽**：BGMは和風のチップチューン（タイトル用と対戦用）。音声ファイルは使わず `sound.js` でその場で鳴らしている。右下のボタンで効果音と一緒に消せる。
- 画数が多い漢字ほど、武器が大きく・重く・遅く・強くなる。
- 技は弱攻撃・強攻撃・ジャンプ攻撃・対空・足払い・ダッシュ・フルスイング・バックステップ。
- 字の形で得意技が変わる：横長は横薙ぎ、縦長は突き、画数の多い詰まった字は叩きつけ。
- **字の形の特徴**（特別な字も含めて、どの字にも自動で効く。入力画面には出さない）
  - 軽い（4画以下）：振りがとても速い
- 卍は、持っている卍そのものを投げるブーメラン。戻ってくるまで手ぶらで、殴れない。弓の必殺技は、いつもの矢が空から降り注ぐ。
  - 先がとがっている（介・今・人の人屋根、十・中・半のように縦棒が突き出た字）：突き刺して出血させる「突き刺し!」
  - かぎがある（礼の乚、子・手の亅、刀・門の𠃌）：足払いで引っかけて転ばせる「引っかけ!」
  - 平らな面がある（一・王・正・口の上下の線）：強攻撃が面打ちになり、吹き飛ばしが大きく、ガードを崩す「面打ち!」
  - 真ん中の縦棒（十・中・申・車）：リーチが少し長く、突きが得意
  - 囲み（口・日・田・国）：ガードが硬く、面打ちでも崩れない
- 竜と龍は同じ字として図鑑に記録される（どちらで勝っても発見になる）。
- ビャンビャン麺の「𰻞」（58画）も特別な字。日本語の入力ではほぼ出せないので、コピーして貼りつける。端末のフォントに無いと□で表示される。
- 特別な効果を持つ漢字が100字ある。その字で勝つと「発見」になり（図鑑に登録）、入力画面に発見数が出る。2026年11月に11字を入れ替えた（外した字：糸・餅・双・速・消・鈍・笑・飛・燃・焔・倍／入れた字：母・筋・鮨・税・罰・悪・魂・乙・鎌・霊・蹴）。外した字を図鑑に登録していた人も、発見数は今の100字だけで数える。
  - 母：攻撃のたびに小言（「ご飯よー!」など）が飛んでいく／筋：当てるたびにムキムキ（最大1.5倍）／鮨：「へいお待ち!」と寿司を投げる／税：課税で相手のHPがじわじわ減る／罰：相手が空振りすると小さな天罰の雷／悪：ときどき背後にワープして不意打ち／魂：まわりを回る人魂が近づいた相手に当たる／乙：「お疲れ様です」でつられた相手がお辞儀して止まる／鎌：HP3割以下の相手に大ダメージ／霊：ときどき透けて攻撃をすり抜ける／蹴：ときどき字を蹴って飛ばす
  - 岩は効果を「とても硬い（受けるダメージが減る）」から「たまに岩を投げる」に変えた（2026年11月）
- 「神」は最初は封印されていて、勝ち抜きで10連勝すると、勝ち抜きを終えたときの最終結果で「漢字ファイターの神」の称号と一緒に封印が解け、図鑑にも入る（封印中はふつうの字と同じで、発見にも数えない）。神はいつも宙に浮いていて、足をそろえて直立したまま歩かずにすーっと滑って動く（進む向きに少し傾き、後ろに金色の光の筋が残る）。離れた相手の頭上にも天罰を落とす（足元に光の輪が出てから少しして光の柱が落ちる。輪から逃げれば外れる）。
- 鬱でやる気を下げられた側は、顔に縦線が出て、青ざめて背中が丸まる。殴られるたび（とときどき）ため息をつき、口から白いもやが出て肩が落ち、「はぁ…」「帰りたい…」と弱音をはく（やる気が下がるほど重い弱音になる）。
- 100字すべて見つけると、隠し字「龘」の封印が解ける（記録は遊んでいる端末のブラウザに保存）。
- CPUは特別な字とふつうの字を半々で選ぶ。
- URLの末尾に `?debug` を付けると当たり判定が見える。

## 英語版
- 端末の言語が日本語以外なら英語で表示される。タイトルの「English／日本語」ボタンでいつでも切り替えられる（選んだ言語は端末に保存）。
- 英語版では、入力欄に英単語（fire、cat など）を打つと、その意味の漢字の候補が出る。特別な字が先に並ぶ。字の意味は入力画面と図鑑にも出る。
- 文言は `i18n.js`（共通の表と切り替え）、`weapon.js`（効果説明）、`game.js`（文の組み立て）にある。

## 絵
- キャラは3Dモデル（`img/fighter.fbx`、元は `3D素材/lee-v2.zip`）。1Pは赤、2Pは青の道着と鉢巻、帯はどちらも黒。
  - **公開するのは暗号化した `img/fighter.dat` だけ。** 素材のライセンス（CGTrader のロイヤリティフリー）で、遊ぶ人がモデルを取り出せないようにすることが求められているため。`img/fighter.fbx`・`fighter_parts.json`・`fighter_red.png`・`fighter_blue.png` はこのフォルダにだけ置き、公開用には入れない。
  - 元ファイルを直したら `node tools/pack_fighter.mjs` で `fighter.dat` を作り直す（`tools/make_public.sh` も最初にこれを実行する）。暗号化と復号は `fighter-pack.js`（ChaCha20）。
  - 色は `img/fighter_red.png` / `img/fighter_blue.png`（元のテクスチャの「CLOTH PRIME」欄を赤・青に、「CLOTH SEC」欄＝帯を黒に塗り替えたもの）。
  - `char3d.js` が three.js（cdn.jsdelivr.net から読み込む）で1人ずつ描いて、ゲームの画面に貼る。骨は毎コマ、ゲームの関節の動き（足・腰・漢字を持つ手の位置）に合わせて曲げる。漢字は奥の腕で持つ（手前の腕で持つと顔が隠れるため）。
  - 漢字を持つ腕は字の手前の端へ向けて伸ばし、届かなかった分は字のほうを拳のすぐ先（少し浮かせて、重ねない）に寄せて描く（当たり判定は動かさない）。寄せた字が自分の体に重なるとき（大きな字・伸びる字）は、重ならないところまで字の向きに離す（`game.js` の `clearOfBody`）。
  - 字を持つ奥の手は手のひら、手前の手は甲をカメラ側に向ける。斜め前から見る角度（`char3d.js` の `YAW`）を広げて顔を見せ、手前の手が顔に重なるときは、あごの下まで下げる。
  - ダメージを受けたときと倒れたときだけ、顔をカメラのほうへ向ける。
  - 足の開きは脚の長さの7割まで（斜めから見ると開きが大きく計算され、腰が落ちて座って見えるため）。手前の右足が後ろ足。
  - 表情と手の形は、3D素材の顔5種・手7種を状態で切り替える（`img/fighter_parts.json` に FBX を base64 でまとめてある）。
    - 顔：ふつう／叫び（攻撃中・必殺技）／驚き（攻撃を受けた・凍った・捕まった）／ニヤリ（当てた直後・勝った）／KO（ダウン・気絶・負け）
    - 手前の手：手刀（構え）／掌底（ガード・弱攻撃）／拳（攻撃）／虎爪（ジャンプ・必殺技）／広げた手（被弾）／丸めた手（気絶）／開いた手（ダウン）
  - 3Dを読み込めないとき（ネットにつながっていない、WebGLが使えない）は、これまでのカプセル型の棒人間で描く。
- 背景は `3D素材/fbx.rar` の道場を three.js で撮った絵。対戦画面とタイトル画面で使う。無くても遊べる。
  - `img/dojo_wide.jpg`（PC・横画面）：部屋の手前（奥の壁から3200）から、目の高さ150で水平に撮った（2400×1600、縦の画角64°）。
  - `img/dojo_tall.jpg`（スマホ縦画面）：同じ位置から高さ300で、カメラは水平のまま枠だけ下へずらして床を多めに映した（下向きに撮ると柱や壁が斜めに傾くため。three.js の `setViewOffset` で、縦の画角100°・1200×2312 の絵の下側 1200×2000 を撮る）。
  - 素材の色はほぼ黒なので、色を付け直した。キャラが引き立つよう全体を淡めにしている：畳は淡い緑（縁は黄緑）、天井は明るいオレンジ、奥の壁は淡い朱色、障子は生成り、柱と壁は明るい木の色。真横（右）から日差しを入れて、畳に格子の影を横縞で落とした（日差しを前後に傾けると縞が斜めになり、絵が傾いて見える）。撮り方は `tools/render_dojo.js` にまとめてある。
  - 絵の中の地平線を、キャラの足元から決まった高さ（PCは120px、スマホは240px）に置いて、画面を覆う大きさに拡大する（`game.js` の `BG` と `bgFit`）。
- 対戦中は、2人の距離に合わせてカメラが寄ったり引いたりする。

## 画数データ
`kanji-data.js` は KANJIDIC2 から自動生成したもの。作り直すときは:

```
perl tools/build_kanji_data.pl kanjidic2.xml.gz kanji-data.js
```

英語の意味データ `kanji-meanings.js` も KANJIDIC2 から作る（常用・人名用など約3000字）:

```
perl tools/build_kanji_meanings.pl kanjidic2.xml.gz kanji-meanings.js
```

字の形の特徴 `kanji-shapes.js` は KanjiVG の筆画データから作る（穴だけは、ゲームの中で描いた字から判定する）:

```
ruby tools/build_kanji_shapes.rb kanjivg-20260714.xml.gz kanji-shapes.js
ruby tools/build_kanji_shapes.rb kanjivg-20260714.xml.gz --show 介礼口   # 判定結果を見る
```

表に無い漢字は、描画したときの黒さから画数を推定する（「推定」と表示される）。
